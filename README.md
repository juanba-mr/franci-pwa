Hermes Seguros es una plataforma integral de gestión de carteras y pólizas diseñada para productores asesores de seguros. Este repositorio contiene la aplicación cliente, construida como una **Progressive Web App (PWA)**, lo que permite a los usuarios instalarla en sus dispositivos móviles y acceder de forma nativa.

![Dashboard Preview](link-a-tu-imagen-del-dashboard-aca)
> *Vista principal del dashboard del cliente.*

## ✨ Características Principales

- **📱 Experiencia Nativa (PWA):** Instalable en iOS y Android, con soporte para notificaciones Web Push.
- **📊 Dashboard de Cliente:** Visualización rápida de pólizas vigentes, estado de pagos y descarga del documento original (PDF).
- **🎛️ Panel de Administrador:** Sistema avanzado para la agencia con métricas en tiempo real, gestión de cartera y alertas de renovaciones.
- **🤖 Ingesta Híbrida con IA:** Interfaz para subir PDFs de pólizas, donde el backend con Inteligencia Artificial extrae automáticamente los datos y los vincula al cliente.
- **⚡ Caché y Estado Global:** Manejo ultra rápido de datos con TanStack Query, reduciendo las llamadas a la API.

## 🛠️ Tecnologías Utilizadas

- **Core:** React 18 + Vite
- **Estilos:** Tailwind CSS + UI Components (shadcn/ui adaptado)
- **Animaciones:** Framer Motion
- **Estado y Fetching:** TanStack Query (React Query)
- **Iconografía:** Lucide React
